- **Attach files to a message** (⇧⌘A). In the composer, pick files from your device, drag them onto it or paste them, including a screenshot. Each file shows its type, name and size while it uploads, can be removed, and the composer says how much of the 25 MB a message may carry is used. Campbooks refuses an empty file, one that would take the message past 25 MB or 20 files, and the file types Gmail and Outlook block (such as `.exe` and `.js`), naming the file and why. If you delete a draft and then undo it, the draft comes back without its uploaded files and says so.
