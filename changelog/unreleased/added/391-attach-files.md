- **Attach files to a message** (⇧⌘U). In the composer, pick files from your device, drag them onto it or paste them, including a screenshot. Each file shows its type, name and size while it uploads, can be removed, and the composer says how much of the 25 MiB a message may carry is used (about 2 MB for an Outlook or Microsoft 365 mailbox, which takes less). Campbooks refuses an empty file, one that would take the message past that limit or 20 files, and the file types Gmail and Outlook block (such as `.exe` and `.js`), naming the file and why. A large file on a slow connection has up to 100 seconds to arrive. If you delete a draft and then undo it, the draft comes back without its uploaded files and says so.
