- **Save a thread to a page, and Scout's page cards** (mail and Scout in pages, with
  `CAMPBOOKS_PAGES__MAIL_SCOUT__ENABLED` on). **Save to page** is in the reader's More menu and on
  Shift P: pick a page you can write to by name (the ones that already link the thread come first)
  or start a new private page, then add a live thread block, a copy of the messages (the dialog
  says who will read the page, and that it is sent to Notion too when it is) or hand over to Scout
  for a summary. The attachments can come along, a file over 20 MB or a refusal is named and
  nothing is added, and every save has an Undo. In Scout's chat, a **page change card** shows where
  a section goes, who will read it (never "private" when anyone else can), whether Notion gets it
  too and the whole text, with Add to page, Edit first and Discard; once added it offers Open page
  and Undo, and a proposal that does not say who reads the page offers no Add to page. A page's
  More menu has **Ask Scout** for a chat about the page.
