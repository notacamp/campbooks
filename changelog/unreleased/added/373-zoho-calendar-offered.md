- **Zoho mailboxes are offered calendar access when the server has Zoho Calendar on** (Settings → Calendar, campbooks-cloud#373). The connection view gains `offers`, the capabilities a connection could still be given (`calendar` for Google, and for Zoho only while `CAMPBOOKS_CONNECTORS__ZOHO_CALENDAR` is on); the page reads it instead of naming providers. `identity.start_link` accepts `capabilities: ["calendar"]` for a reconnect.
