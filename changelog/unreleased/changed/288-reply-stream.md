- **You can watch Scout write your reply.** In the Reply dialog on the web, Scout's thinking
  shows in a small grey box, then the reply types itself into the draft. A slow reply no
  longer fails after 30 seconds: Scout gets up to two minutes, and says so plainly if it
  takes too long. When you type "1 and 3, warmer", Scout now knows which suggestions you
  mean. The desktop app waits longer for a reply too. Self-hosters can ask a reasoning
  model to think less with `CAMPBOOKS_AI__<ROLE>__REASONING_EFFORT` (off by default).
