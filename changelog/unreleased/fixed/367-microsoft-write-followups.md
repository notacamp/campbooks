- **Outlook mail (off by default) keeps what you did and what was sent in step.** Where the
  instance turns Microsoft mail on, a message Microsoft accepted for sending is always shown as
  sent, even when its copy in Sent Items is late or filed under another id, so you are never told
  to send it again; a message Microsoft refuses to show before a change is reported as refused
  and shown as it is there, not as gone; a change whose move had nowhere to go shows the message
  as Outlook has it; a message deleted while Microsoft's answer was lost still goes back to its
  folder when you restore it; changes still waiting when Microsoft mail is turned off end as not
  supported; and a send Microsoft slows down marks the connection as slowed down.
